# Jetsam whitepaper

**Jetsam: A Proof-Carrying Layer 1** — whitepaper **v3.1**, 15 October 2026.

This repository holds the canonical text of the Jetsam whitepaper and its
rendered forms. The same document is served at <https://jetsamchain.com/whitepaper/>.

| file | what it is |
|---|---|
| `whitepaper.md` | the source text (Markdown, English) |
| `whitepaper.html` | a self-contained HTML rendering of the same text, no external requests |
| `jetsam-whitepaper.txt` | a plain-text rendering (lines of at most 100 characters) for chat clients |
| `SHA256SUMS` | checksums of the three files above |
